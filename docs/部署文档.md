# 部署文档（占位框架）

> 完整版将在系统可运行后补充，此处先给出部署步骤框架。

## 1. 环境准备
- Python 3.11+
- Node.js 18+
- MySQL 8
- Redis

## 2. 数据库初始化
```bash
mysql -u root -p < database/schema.sql
mysql -u root -p < database/init_data.sql
```

## 3. 后端 Flask
```bash
cd backend
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
# 配置 .env（数据库、Redis、模型服务地址）
python run.py   # http://127.0.0.1:5000
```

## 4. 模型服务（独立部署）
```bash
cd ml
pip install -r requirements.txt
# sentiment/server.py   -> 127.0.0.1:5051
# topic/server.py       -> 127.0.0.1:5052
```

## 5. 前端 React
```bash
cd frontend
npm install
npm run dev   # http://127.0.0.1:5173
# 生产构建：npm run build，产物在 dist/
```
